# pysuqu 2.0.4

Released on August 14, 2026, `pysuqu 2.0.4` introduces transmission-chain
simulation from the AWG reference plane to the qubit reference plane. The
release connects reusable line models to waveform generation and gate
simulation while keeping intermediate signals available for inspection.

## Highlights

- Build ordered single-line chains from attenuation, delay, arbitrary transfer
  functions, and FIR, IIR, or SOS digital filters.
- Load full-matrix Touchstone `.sNp` data, select individual `Sij` paths, or
  propagate aligned signal bundles through MIMO submatrices.
- Attach a chain to `ChannelSchedule`, provide a gate-level default, or pass an
  explicit override when generating or simulating a waveform.
- Fit derivative-basis precorrection coefficients against a sampled frequency
  response and reuse the resulting design as a transmission stage.
- Capture stage-by-stage histories and compare AWG-side and qubit-side traces
  with the public plotting helpers.

## Stable Imports

The main workflow is available from the stable `pysuqu.qubit` surface:

```python
from pysuqu.qubit import (
    AttenuatorStage,
    ChannelSchedule,
    DelayStage,
    TouchstoneStage,
    TransmissionChain,
    WaveformGenerator,
)
```

Focused waveform code can continue importing the same transmission objects
from `pysuqu.funclib.transmission`.
